## 1. Portfolio Sitemap

A minimal, purpose-built sitemap designed to guide technical leads from initial landing to verifying technical proof:

```text
[ Hero / Landing ] ────► [ Case Study: Search Intelligence ] ────► [ Action Playbook & Contact ]
  • Claim Statement          • 30k Dataset & GroupKFold Split        • Human-in-the-Loop Rules
  • Primary Skill            • Baseline vs Model (1.6x Precision)    • GitHub Repo & Contact Link
  • Primary CTA              • Live receipts & Interactive HTML
```

* **Page 1: Hero / Landing:** Defines the primary proof claim ("Honest, leakage-free ML scoring systems") and primary CTA.
* **Page 2: Search Intelligence Case Study:** Presents the capstone paper, model benchmarks (Random Forest Precision@50 = 0.8400), feature importances, and leakage audit.
* **Page 3: Content Action Playbook & Contact:** Demonstrates operational reason codes, strict no-go automation rules, and provides direct contact links for technical engagements.

## 2. Claude Project Pressure-Test Prompt & Output

* **Pressure-Test Prompt:**
  > "Act as a critical hiring manager evaluating my portfolio sitemap. My claim is 'I design honest, leakage-free ML scoring systems.' Test whether every page on this sitemap directly proves this claim or if any page is unnecessary decoration."

* **AI Feedback & Refinement Note:**
  > "The 3-page flow is lean and friction-free. Every section directly supports the core claim through verifiable receipts rather than fluff. Key refinement made: Combined the standalone About page directly into the Case Study methodology section so the visitor reaches proof in fewer clicks."
